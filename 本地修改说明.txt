顶奢本地批量修改说明
====================

一、修改全部资料
1. 打开“顶奢_整站资料批量编辑.xlsx”。
2. 资料页、首页、城市首页、固定页面和页脚均已放入不同工作表；首页预约流程、随机推荐和常见问题在“首页设置”中修改。
3. 只修改黄色单元格；现有城市代码、page_code、字段代码、网址等灰色技术字段不要修改。
4. 保存并关闭 Excel。
5. 双击“一键更新网站.bat”。
6. 本地预览时双击 dist/index.html，不要直接打开 dist/shanghai/ 或任一资料文件夹。

二、更换图片和视频
每套资料对应一个 photos 文件夹，例如：
photos/shanghai-model-001/

放入：
01.jpg  主图和资料卡图片
02.jpg  第二张图片
03.jpg  第三张图片
profile.mp4  视频（可选）

图片也支持 jpeg、png、webp、avif。建议统一使用 800×1000 的竖图。
在工作表“处理图片”列填写“是”后运行脚本，会提醒缺少哪些媒体文件。

三、发布和收录
1. 现有 50 个资料模板默认“已发布、允许收录=否、内容审核=待完善”。页面可以访问，但不会进入 Sitemap。
2. 真实内容完成前，不要把“允许收录”改为“是”。
3. 开启收录前，必须替换模板文字，填写独立 SEO、简介、详情说明、正文、首次发布日期和最后更新日期。
4. 至少添加真实主图 01；SEO 描述、正文1、图片 ALT、图片说明、视频标题和视频描述由“页面名称”强制自动生成。修改页面名称后，一键更新会同步修改工作表和网页内容，不需要逐格修改。
5. 有视频时只需放入 profile.mp4；视频标题、描述、封面、上传日期和时长都可以留空。需要填写时，时长使用 ISO 8601 格式，例如 PT1M30S。
6. 全部检查完成后，把“内容审核状态”改为“已完成”，再把“允许收录”改为“是”。

四、新增城市和资料
1. 在“城市首页”下一空白行填写新城市，先设为“草稿”和“不允许收录”。
2. 在“资料批量编辑”下一空白行填写资料，slug 使用 model-001 这类格式。
3. 新资料对应媒体文件夹为 photos/城市代码-model-编号/。
4. 运行更新脚本后，新城市和资料会自动生成页面；满足收录条件后才会进入 Sitemap。

五、上传 GitHub
第一次上传：
1. 在 GitHub 新建空仓库。
2. 在本文件夹打开命令行，连接仓库并推送 main 分支。
3. GitHub 仓库 Settings → Pages → Source 选择 GitHub Actions。

以后更新：
1. 修改并保存工作表。
2. 双击“一键更新网站.bat”。
3. 双击“上传到GitHub.bat”。推送成功后会提交本次变化的 URL 到 IndexNow。

GitHub Pages 会自动发布 dist 文件夹。

注意：
- 不要删除 dist、profiles.json、tools、verification 和 .github 文件夹。
- 不要修改现有 city_slug、slug、页面URL和图片文件夹等灰色字段。
- hqq2.com 使用自己的部署平台时，上传 dist 文件夹内的全部内容即可。
- 首页与详情页的资料推荐会在每次打开页面时随机变化；工作表中的资料发布状态仍决定可推荐的内容。
