# 顶奢 hqq2.com

静态城市资料展示站。当前包含 5 个城市和 50 个资料模板，后续可在工作表中继续增加城市与资料。

现有 50 个模板详情页保留访问入口，但默认 `noindex`，不会进入 Sitemap。只有真实内容和媒体完成、内容审核通过，并在工作表中开启“允许收录”后，详情页才会进入搜索引擎站点地图。

## 本地批量修改

1. 打开 `顶奢_整站资料批量编辑.xlsx`。
2. 在 `资料批量编辑`、`首页设置`、`城市首页`、`固定页面`、`页脚设置` 中修改黄色单元格。首页预约流程、随机推荐标题与数量、常见问题也已加入 `首页设置`。
3. 保存并关闭 Excel。
4. Windows 双击 `一键更新网站.bat`。

也可以在命令行运行：

```bash
python import_profiles_excel.py "顶奢_整站资料批量编辑.xlsx"
```

脚本会先校验发布状态、收录条件、日期、图片 ALT 和视频元数据，再更新 `profiles.json` 与 `site_content.json`，重新生成首页、页脚、城市页、固定页面、详情页、随机相关推荐、响应式图片、Sitemap 和 `dist` 部署目录。最后会自动检查 canonical、robots、结构化数据、重复标题、内部链接和缺失资源。

本地预览时请双击 `dist/index.html`。全站页面链接已经明确指向各目录内的 `index.html`，不要直接打开 `dist/shanghai/` 或资料文件夹，否则 Windows 浏览器会把文件夹显示成目录索引。

## 新增城市和资料

- 在“城市首页”下一空白行填写新城市。先使用“草稿”和“不允许收录”，内容完成后再发布。
- 在“资料批量编辑”下一空白行填写资料。`slug` 使用 `model-001` 这类格式，同一城市内不能重复。
- 开启收录前，必须填写独立 SEO 标题、描述、简介、详情说明、正文、首次发布日期、最后更新日期，并把“内容审核状态”设为“已完成”。
- 至少要有真实主图 `01`。SEO 描述、正文1、图片 ALT、图片说明、视频标题和视频描述由“页面名称”强制自动生成；修改页面名称后，Excel 中对应单元格和网页内容都会同步更新，不需要逐格修改。
- 有视频时只需放入 `profile.mp4`；视频标题、描述、封面、上传日期和时长都可以留空，系统会自动补齐可用信息。需要填写时，时长使用 ISO 8601 格式，例如 `PT1M30S`。

## 更新图片和视频

每个详情页对应一个媒体目录，例如：

```text
photos/shanghai-model-001/
├─ 01.jpg
├─ 02.jpg
├─ 03.jpg
└─ profile.mp4（可选）
```

图片支持 jpg、jpeg、png、webp、avif。推荐使用 800×1000 的竖图。

## 上传 GitHub

项目已经包含 `.github/workflows/pages.yml`。上传到 GitHub 的 `main` 分支后，在仓库 `Settings → Pages` 中选择 `GitHub Actions`，GitHub Pages 会自动发布 `dist` 文件夹。

以后每次本地更新后，可以双击 `上传到GitHub.bat` 提交并推送。推送成功后，脚本只向 IndexNow 提交新增、更新、下线或改为不收录的 URL。

如使用其他托管平台或直接部署 `hqq2.com`，上传 `dist` 文件夹内的全部内容即可。
